# Meneso Consulting — HTML presentation demo

Open `index.html` in a browser. No installation or build is required.

Includes responsive layouts, mobile navigation, floating WhatsApp contact, a scripted AI assistant preview and an enquiry form that prepares an email draft. The assistant is a local demo, not a live AI model. A production AI assistant would need a server integration. WhatsApp uses the mobile number listed on the original website; confirm that it is WhatsApp-enabled before production use.

Company information was imported from the original home, about, services, contact and gallery pages at https://www.menesoconsulting.co.za/. The demo includes the original logo, two leadership portraits and all 49 gallery images stored locally in `assets/`. It also includes the published company background, vision and mission, leadership qualifications, employment and project history, service policies and both email addresses. Original page snapshots are retained in `source-pages/` and `original.html`.

The design uses Meneso’s original blue identity and local gallery photography throughout. The homepage features a full-width photograph of Meneso’s premises, quotation and service actions, and direct links to the three service groups. Google Fonts require an internet connection; system fonts provide a fallback. Keep `styles.css`, `home.css`, `motion.js` and the `assets/` folder alongside `index.html` when sharing the demo. Qualifications, project values and registration details reflect the source website and have not been independently verified.

Headings reveal word by word as the page scrolls, with eased opacity, movement and blur. The hero uses a staggered text entrance and image reveal. Reduced-motion preferences are respected. Company details expand on request, and the complete 49-image gallery includes a keyboard-accessible image viewer.
